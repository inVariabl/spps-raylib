St. Paul's Postal Service

Browser build. Click the canvas before playing so the game can keep function keys, arrows, tab, and shift under your control.

This web version is not the full desktop game. It is a lightweight browser build with simplified rendering and without the full GLB model presentation.

Primary Controls

`F1` or `1` enters first-person view.

`F3` or `3` returns to the isometric view.

`WASD`, arrows, and mouse input behave the same as desktop once the canvas is focused.

Browser Notes

The page now bridges browser keyboard events straight into the game for `F1`, `F2`, `F3`, `F5`, arrows, `TAB`, `SPACE`, both shift keys, and the main letter controls.

The web build disables the custom shadow shader path for compatibility, so `F2` will not turn desktop shadows back on.

Voyage Controls

Arrow keys steer the ship. `Shift` still boosts repairs and morale exactly as it does on desktop.

`TAB` still swaps to the below-deck view during the voyage.
